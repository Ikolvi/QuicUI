# QuicUI Engine Build Scripts

## Overview

These scripts build the Flutter engine with QuicUI Code Push support and test the OTA update functionality.

## Build Scripts

### 1. `build_all.sh` - Master Script ⭐
**Recommended for first-time builds**

Orchestrates the complete build process:
- Checks which engines are already built
- Guides you through Android + Host engine builds
- Builds test app with `--local-engine`
- Provides next steps for testing

```bash
./build_all.sh
```

### 2. `build_android_engine.sh` - Android Engine
Builds the Android ARM64 engine with QuicUI modifications.

**Features:**
- Exports all required environment variables
- Configures GN if needed
- Verifies QuicUI modifications in output
- Logs to `/tmp/android_build_YYYYMMDD_HHMMSS.log`

**Time:** 1-2 hours  
**Output:** `out/android_release_arm64/flutter.jar` and `libflutter.so`

```bash
./build_android_engine.sh
```

### 3. `build_host_engine.sh` - Host Engine
Builds the host engine required for `--local-engine` builds.

**Features:**
- Exports all required environment variables
- Generates `package_config.json` if missing
- Configures GN if needed
- Logs to `/tmp/host_build_YYYYMMDD_HHMMSS.log`

**Time:** 1-2 hours  
**Output:** `out/host_release/` (gen_snapshot, flutter_tester, etc.)

```bash
./build_host_engine.sh
```

### 4. `monitor_host_build.sh` - Build Monitor
Real-time monitoring of host engine build progress.

**Features:**
- Shows current progress (step X/6301)
- Displays percentage complete
- Shows recent build steps
- Detects errors and completion
- Auto-refreshes every 5 seconds

```bash
./monitor_host_build.sh
```

### 5. `test_apps/test_app_fresh/build_with_local_engine.sh` - App Builder
Builds the test app with the custom engine.

**Uses:**
```bash
flutter build apk --release \
  --local-engine-src-path=/Volumes/DoWonder2/quicui_engine_build/engine_full/src \
  --local-engine=android_release_arm64 \
  --local-engine-host=host_release
```

**Time:** 2-5 minutes  
**Output:** `build/app/outputs/flutter-apk/app-release.apk`

```bash
cd test_apps/test_app_fresh
./build_with_local_engine.sh
```

## Build Order

1. **Android Engine** (can run in parallel with Host)
   - Required for APK
   - Contains ConfigureQuicUI C++ code
   - Outputs: flutter.jar, libflutter.so

2. **Host Engine** (can run in parallel with Android)
   - Required for `--local-engine` builds
   - Contains gen_snapshot, flutter_tester
   - Outputs: dart-sdk/, gen_snapshot, etc.

3. **Test App**
   - Requires BOTH engines to be built
   - Uses `--local-engine` flags
   - Links against custom engine

## Testing OTA Updates

After building everything:

1. **Start backend:**
   ```bash
   cd packages/quicui_backend
   dart run bin/server.dart
   ```

2. **Install app (v1.0.0):**
   ```bash
   cd test_apps/test_app_fresh
   adb install -r build/app/outputs/flutter-apk/app-release.apk
   ```

3. **Launch app:**
   - Should show NO counter button (v1.0.0)

4. **Trigger update:**
   - Tap "Test Code Push" button
   - Wait for patch download (~4.5 MB)
   - Patch will install to code_cache

5. **Restart app:**
   - Force stop app
   - Launch again
   - **Counter button should appear** (v1.0.1) 🎉

## Troubleshooting

### Build fails with "vpython3: command not found"
Ensure depot_tools is in PATH:
```bash
export PATH="/Volumes/DoWonder2/quicui_engine_build/depot_tools:$PATH"
```

### Build fails with "package_config.json not found"
Run dart pub get:
```bash
cd /Volumes/DoWonder2/quicui_engine_build/engine_full/src/flutter
./prebuilts/macos-arm64/dart-sdk/bin/dart pub get
```

### ConfigureQuicUI not found in libflutter.so
Verify the source has the modifications:
```bash
grep -n "ConfigureQuicUI" engine_src/shell/platform/android/flutter_main.cc
```

### App doesn't use custom engine
Must use `--local-engine` flags:
```bash
flutter build apk --release \
  --local-engine-src-path=... \
  --local-engine=android_release_arm64 \
  --local-engine-host=host_release
```

# Changelog

## 1.0.0

- Initial public release on pub.dev
- `quicui init` - Initialize QuicUI in Flutter projects with auto API key generation
- `quicui release` - Build and upload baseline releases
- `quicui patch` - Generate and upload binary diff patches
- `quicui engine download` - Download QuicUI Flutter SDK
- `quicui status` - Check project status and server connectivity
- Automatic SDK management (isolated from system Flutter)
- Supabase backend integration
- Support for Android arm64 and x86_64 architectures
